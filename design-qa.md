# Fast Lane design QA

Визуальный источник: `design/reference-fastlane-dashboard.png`. Проверка всегда
делается на реальном LuCI, а не только на локальной HTML-копии.

## Обязательные состояния

- VPN выключен, авто включается, авто работает, ручной сервер подключён.
- Идёт GET-проверка: общий прогресс и loader конкретных серверов.
- Проверка завершена: задержка, ошибка и «не проверен» не противоречат статусу.
- Один источник; два и более источника; длинная скроллируемая полоса источников.
- Источник обновляется, не обновился, скоро истекает и истёк.
- Модалки добавления URL и нескольких YAML-файлов.
- Пустой список, длинные названия, неизвестная страна и недоступный сервер.
- Desktop и mobile; светлая оболочка LuCI вокруг тёмного Fast Lane.

## Компоновка

- Навигация: `VPN / Маршруты / Диагностика / Настройки`.
- Статус VPN, фактический сервер, источник, `Пинг (GET)` и режим читаются как одна строка.
- `Все серверы` отсутствует при одном источнике и появляется при двух.
- Действия источника зафиксированы справа; удаление скрыто для общего пула.
- Фильтры и действия не создают ломаных разделителей.
- На мобильном флаг, имя и адрес образуют один блок; протокол, пинг и статус равномерно распределены.
- Страница не имеет горизонтального скролла на ширине 390 CSS px.

## Поведение

- Открыт только один row-menu; клик вне, Escape и действие закрывают его сразу.
- Скрытие сервера меняет текущий список без перезагрузки страницы.
- Переход на другую вкладку не отменяет уже поставленную в очередь GET-проверку.
- После повторного входа UI получает свежий прогресс, пинги и фактический активный сервер с бэкенда.
- Сортировка по пингу помещает непроверенные и недоступные серверы после измеренных.
- Истёкшие серверы доступны только внутри своего источника и не имеют действий подключения.

## Визуальные правила

- Тёмные цельные поверхности, тёплый светлый текст, мятный активный статус, янтарный пинг и красный только для ошибки/удаления.
- Серверы — строки таблицы, а не набор карточек.
- Тост короткий, выровнен влево и исчезает сам; отдельный крестик не нужен.
- Контролы имеют видимый keyboard focus и область нажатия не меньше 44 px.
- Статус передаётся не только цветом.

## Приёмка изменения

1. Запустить `node test/luci/runtime_smoke.js .`.
2. Проверить затронутые состояния на desktop и mobile.
3. Приложить в pull request скриншоты до/после для видимых правок.
4. Отдельно написать, что проверено на реальном роутере и что не проверено.

Результат считается пройденным только для перечисленных состояний; общий внешний
вид страницы не заменяет функциональную проверку.
